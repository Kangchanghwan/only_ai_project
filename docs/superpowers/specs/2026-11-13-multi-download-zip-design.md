# 여러 파일 받기: ZIP 묶음 + 하나씩 받기 (2026-11-13)

## 문제
선택한 파일 여러 개를 받으면 `useDownload.downloadParallel`이 0.25초 간격으로 숨은 `<a>`를 연달아 눌렀다.
브라우저는 사이트가 연달아 시작하는 다운로드를 막거나(크롬 "여러 파일 다운로드" 제한) 놓친다.
운영 사이트 재현(헤드리스 크롬, 폰 폭, 6개): 지연 없음 5/6, 응답 지연 0.3초 1/6. 화면은 전부 성공으로 표시했다.

## 결정 (owner 승인 2026-11-13)
- 2개 이상은 **ZIP 하나**로 받는다. 압축하지 않고 묶기만 한다(stored). 사진·영상은 이미 압축돼 있어 이득이 없고 시간만 든다.
- **큰 파일(200MB 초과)은 ZIP에서 빼서** 하나씩 받는다(브라우저 다운로드 관리자: 백그라운드·이어받기).
- 묶음 한도: 서비스워커 스트리밍 500MB, 메모리 방식(아이폰·서비스워커 없음) 300MB. 넘으면 묶음을 나눈다.
- 다운로드가 2건 이상 필요하면 **"여러 파일 받기" 시트**를 띄우고 첫 건만 바로 시작한다. 나머지는 사용자가 버튼을 눌러 받는다(사용자가 직접 누른 다운로드는 막히지 않는다).
- 결과 문구는 사실대로: ZIP은 다 받은 뒤 "받았어요", 브라우저 직접 받기는 "받기 시작했어요".

## 구조
| 파일 | 역할 |
|---|---|
| `src/utils/zipWriter.js` | ZIP 머리글·CRC32·크기 계산 (순수 함수). Zip64 없음: 묶음 한도가 500MB라 4GB에 닿지 않는다 |
| `src/utils/downloadPlan.js` | 선택을 `zip`/`file` 항목으로 나눈다. ZIP 안 파일 이름 정리·중복 이름 번호 붙이기 |
| `src/services/zipDownloader.js` | 서비스워커 스트리밍(`/__zip/<token>`) 또는 메모리 방식으로 ZIP 저장 |
| `public/sw.js` | `ZIP_REGISTER` 메시지, `/__zip/<token>` 응답 스트림. 번들되지 않아 머리글 코드를 따로 두고, 테스트로 `zipWriter.js`와 바이트 단위 일치를 검사 |
| `src/components/MultiDownloadSheet.vue` | 항목별 [받기]/진행률/✓/다시 받기 |
| `App.vue` | `handleDownloadParallel`이 계획을 세워 1건이면 바로, 2건 이상이면 시트. 시트가 열린 동안 "다음엔 더 빨리" 안내를 띄우지 않는다 |
| `DownloadPage.vue` | 여러 파일 QR 받기 화면(`#/download?r=&f=`). 같은 방식으로 목록을 보여 주고 첫 건만 자동 시작. 크기는 받기 주소 응답 길이로 추정(텍스트 파일은 저장소가 압축해 길이를 주지 않아 하나씩 받기로) |

## ZIP 규격
- 항목마다: 로컬 머리글(플래그 bit3 데이터 서술자 + bit11 UTF-8 이름, 방식 0, CRC·크기 0) → 파일 바이트 → 데이터 서술자(서명 포함 16바이트) → 끝에 중앙 디렉터리·끝 레코드.
- 전체 크기를 미리 계산해 `Content-Length`로 준다(브라우저 진행률). 받은 바이트 수가 목록 크기와 다르면 스트림을 오류로 끝낸다(깨진 ZIP을 성공처럼 남기지 않는다).
- QR 받기 화면처럼 크기가 추정값이면(`exact:false`) 길이 검사와 `Content-Length`를 생략한다(데이터 서술자·중앙 디렉터리에는 실제 크기가 들어간다).
- 파일 주소는 각 파일을 받기 직전에 서비스워커가 `POST /api/r2/download-urls`로 새로 받는다(서명 주소 10분 만료 대비).

## 확인한 것 (2026-11-13, 운영 API·R2에 이 빌드를 붙인 헤드리스 크롬, 폰 폭 390)
- 5개(한글 이름 포함) → ZIP 1개, 응답 지연 0.3초에서도 누락 없음. `unzip -t` 통과, `ditto`로 풀어 원본과 해시 일치.
- 아이폰 UA(메모리 방식) → ZIP 1개, 해시 일치.
- 205MB 파일 섞음 → 시트: ZIP 즉시 + 큰 파일은 눌러서 받기, 큰 파일 해시 일치.
- QR 받기 화면 → ZIP(4개) 자동 + 큰 파일·텍스트 파일 눌러 받기.
- 바꾸기 전 같은 조건: 6개 중 5개(지연 없음), 1개(지연 0.3초).
