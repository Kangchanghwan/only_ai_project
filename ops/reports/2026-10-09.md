### GeekNews Show GN 초안 (owner 검토용)
- 유형: Show / URL: https://www.clipboardapp.org
- 제목 ("Show GN:"은 자동으로 붙음): Clipboard Share - 같은 와이파이면 코드 입력 없이 폰↔PC로 파일·텍스트를 옮기는 웹 클립보드
- 본문:

```
학교 PC와 제 폰 사이에서 사진이나 텍스트를 옮길 때마다 카톡 PC 로그인이나 USB를 찾는 게 번거로워서 만든 웹 서비스입니다. 가입, 앱 설치, 코드 입력 없이 같은 와이파이에 있는 기기들이 브라우저에서 자동으로 한 방에 묶입니다.

**어떻게 묶이나**
- 접속한 공인 IP를 서버 비밀키로 HMAC 해서 Socket.IO 룸 이름으로 씁니다. 룸 이름과 업로드 한도 키에는 IP 원문 대신 HMAC 값만 씁니다.
- 그래서 6자리 코드나 QR 페어링 단계가 없습니다. 대신 학교·회사처럼 같은 공인 IP를 쓰는 다른 사람에게도 보일 수 있어서, 연결된 기기 목록(동물 이름표 + 기기·브라우저)을 화면에 보여 주고 민감한 자료는 쓰지 말라고 안내합니다.
- 다른 네트워크끼리 주고받으려면 "전체 공유" 탭을 직접 골라야 합니다. 이 탭은 모르는 사람도 볼 수 있다고 경고를 띄웁니다.

**파일**
- 파일당 최대 5GB, 방 전체 10GB입니다. 100MB가 넘으면 R2 멀티파트로 나눠 올리고, 와이파이가 끊겨도 이어서 올립니다.
- 모든 기기가 나가면 잠시 후 지우고, 접속 중이어도 최대 1일 뒤 정리합니다.
- 지금은 서버(클라우드) 경유 전송입니다. WebRTC 직접 전송은 연결 가능 비율만 측정하는 단계입니다.

**만든 방식**
- 코드 대부분을 Claude Code로 작성했습니다. Vue + Node(Socket.IO) + Cloudflare R2이고 소스는 공개되어 있습니다: https://github.com/Kangchanghwan/only_ai_project
- 10월부터는 성장 작업도 에이전트에게 맡겨 보는 중입니다. 매일 GA4·Search Console 수치를 읽어 결정론적 스크립트로 등급을 매기고, 개선안을 intent 문서로 쓴 다음, 허용된 경로(가이드 페이지·카피)만 CI 게이트를 통과하면 자동 머지됩니다. 이번 주에는 에이전트가 바꾼 영어 타이틀이 반영된 직후 "online clipboard" 검색 순위가 빠져서, 같은 루프로 원복하기도 했습니다.
```
