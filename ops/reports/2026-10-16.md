## Product Hunt 초안 보강 (lock-campaign 4절, owner 확인 필요)
비공개 초안 https://www.producthunt.com/products/clipboard-share?launch=clipboard-share 에 아래를 반영했다. 아직 예약(Schedule) 전.

- Description (488/500):
  > Open clipboardapp.org on two devices on the same Wi-Fi and they find each other automatically. No account, no app, no pairing code. Paste text or a screenshot, or drop files up to 5GB each; they appear on the other device with the sender's animal name tag. Sending an ID scan or a contract? Lock that file with a password: it is encrypted in your browser before upload, and only people with the password (or a one-file QR link) can open it. Files are cleaned up within a day. Open source.
  - 글자 수 때문에 "Uploads over 100MB … resume"와 "Works in any modern browser … PWA" 문장은 뺐다 (갤러리 2번이 이어올리기를 보여 줌).
- 메이커 첫 댓글: "Honest limits" 문단만 바꿨다. 나머지는 10-13 문구 그대로.
  > Honest limits: on school, office or cafe networks, other people on the same network can see the "Same network" room. So this week I added an optional password lock: a locked file's name and content are encrypted in your browser (PBKDF2 + AES-GCM) before upload, the server only gets the ciphertext and a password check value, and you can hand it over with a QR code that carries that one file's key after the #. Text and device labels are not locked, and a forgotten password can't be recovered.
  - 예전 문장 "so it's not for sensitive files. It is not end-to-end encrypted."는 잠금 출시로 사실이 바뀌어 지웠다.
- 갤러리 4번째: "Lock a file with a password." (1270x760, 영어 UI 실제 캡처: 보낸 쪽 lease-contract-scan.pdf 잠긴 카드 / 받는 쪽 가려진 이름 + Unlock). 칩: Optional, per file · File name hidden too · Hand over with a QR · Text is not locked.
