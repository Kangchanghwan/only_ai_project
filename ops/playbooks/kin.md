# 지식iN 답변 (2026-10-02 중단, 참고용)

> owner 결정으로 중단. 일일 루프에서 실행하지 않는다. 다시 켜려면 daily-loop.md 일정표에 owner가 추가한다.

자동 게시. 화·금 최대 3개, 토·일 최대 2개. 하루 합계 3개를 넘기지 않는다 (스팸 판정 방지).

## 개수보다 적합도 (2026-10-02 첫 실행 피드백)
- 3개는 상한이지 목표가 아니다. "적합도 높음"만 답한다. 없으면 0개로 끝내고 보고에 "적합 질문 없음"이라고 적는다.
- 적합도 높음 = 질문자가 지금 두 기기(폰↔PC, PC↔PC 등) 사이로 파일·사진·텍스트를 옮기려 하고, 같은 공간/같은 와이파이일 가능성이 높은 경우.
- 제외: 저장공간 부족·용량 정리·아이클라우드 요금/오류처럼 옮기기가 본론이 아닌 질문, 기존 답변이 이미 충분히 자세한 질문(보충 답변 금지), 채택 완료 질문.
- 답변 사이 최소 3분 간격 (연속 게시 시 CAPTCHA가 뜬다).
- 링크는 본문에 1번만. 자동 생성되는 큰 링크 카드는 지울 수 있으면 지운다 (광고처럼 보임).
- 질문 찾기: 키워드 검색 결과는 "최근 답변일" 정렬이라 오래된 질문이 섞인다. 질문 작성일을 반드시 확인하고, 카테고리별 최신 질문 목록(안드로이드·아이폰·윈도우 > 파일 전송/사진)을 먼저 훑는다.
같은 문장을 복사해 붙이지 말고 질문마다 상황에 맞게 다시 쓴다.

## 질문 찾기와 답변 규칙
https://kin.naver.com 에서 최근 7일 이내 미해결/답변 적은 질문을 최신순으로 검색 (kin.naver.com/search/list.naver?query=..&sort=date&period=1w 를 fetch로 파싱하면 빠름): 핸드폰 사진 컴퓨터로 옮기기, 핸드폰 동영상 컴퓨터로, 아이폰 동영상 컴퓨터로, 대용량 파일 보내기, 컴퓨터끼리 파일 옮기기, 노트북 파일 옮기기 USB 없이, 맥 윈도우 파일, 아이폰 pdf 넣기, 아이패드 파일 컴퓨터로, 갤럭시 사진 맥북, PC방 파일 옮기기, 폰 컴퓨터 텍스트 복사, 에어드롭 윈도우, 케이블 없이 사진 옮기기. 루틴 메모리에 이미 다룬 질문 docId를 기록하고 중복 제외.
제외: 같은 와이파이가 아닌 상황(타지 가족에게 전송 등), 데이터 복구·기기 고장 문제, 이미 채택이 끝나 답변이 과포화된 질문. "전체 공유"를 대안으로 권하지 말 것.
답변 규칙: 존댓말 300~600자, 질문자 상황에 맞는 일반적 방법 1~2개를 먼저 솔직히 안내한 뒤, 같은 와이파이라면 clipboardapp.org 방법을 단계별(PC에서 열기 → 폰에서 열기 → 연결된 기기 목록에서 상대 기기 이름표 확인 → 붙여넣기/파일 선택 → 다운로드)로 안내. 동영상·대용량 질문이면 "파일당 5GB, 끊겨도 이어서 올라감"을 언급. 링크는 1개만, "제가 만든 사이트인데" 식으로 밝혀도 됨.

## 게시
- 질문 페이지 답변 폼에 입력해 게시. 게시 URL과 docId를 루틴 메모리와 리포트에 기록.
- 신고·숨김 처리된 답변이 생기면 그 주는 지식iN을 중단하고 보고.
