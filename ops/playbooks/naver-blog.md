## 제품 사실 (2026-10-01 기준, PR #35~#46 반영)
매 실행마다 라이브 사이트(업로드 카드 문구, "보관·사용 안내", 도움말 ? 모달)에서 아래 수치가 그대로인지 먼저 확인하고, 다르면 사이트 값을 따르세요.
- 같은 와이파이(같은 공인 IP)의 기기들이 브라우저에서 자동 연결되는 무료 온라인 클립보드. 회원가입·앱 설치 없음. 아이폰·갤럭시·아이패드·윈도우·맥·크롬북 모두 브라우저만 있으면 됨. PWA 설치 시 공유 시트로 바로 보내기 가능.
- 대용량: 파일당 최대 5GB, 방 전체 10GB, IP당 하루 업로드 20GB. 100MB가 넘는 파일은 조각으로 나눠 올리고, 와이파이가 끊겨도 이어서 올림. 업로드 중 취소/모두 취소 가능. (예전 "최대 100MB" 문구는 더 이상 쓰지 말 것)
- 보관: 모든 기기가 나가면 잠시 후 삭제, 접속 중이어도 파일은 최대 약 1일 뒤 정리. 계정·기록 없음.
- 기기 이름표: 접속하면 "수줍은 햄스터" 같은 동물 이름이 붙고(다시 뽑기 가능), 연결된 기기 목록에 기기·브라우저(예: Mac 크롬, 갤럭시 삼성 인터넷)가 보이며, 받은 파일·텍스트에 보낸 기기가 표시됨. 새 기기가 들어오면 알림. 이름표는 본인 인증이 아니라 기기 구분용.
- 넓은 화면(PC)에서는 왼쪽에 연결된 기기 패널, 오른쪽에 파일/텍스트 작업 영역이 나오는 반응형 레이아웃. 텍스트 탭에서 직접 입력해 "공유"로 보낼 수도 있음. 하단에 "건의하기" 링크.
- 안전 문구 필수: "같은 네트워크"라도 학교·회사·카페처럼 같은 네트워크를 쓰는 다른 사람에게 보일 수 있음. "전체 공유"는 모르는 사람도 볼 수 있으므로 민감한 자료는 쓰지 말 것.
- 쓰지 말 것: P2P 직접 전송(현재 연결 점검만 있고 실제 전송은 서버/클라우드 경유), 종단간 암호화, 보관 기간 보장, "학생 결과물 받기" 활용 사례(사용자가 거부함).

## 활용 대상 확장 (주제 선정과 본문 "이런 분께 좋아요"에 반영)
- 기존: 폰↔PC 사진·텍스트 옮기기, PC방/회사/학교 공용 PC.
- 추가: 원본 화질 동영상을 PC로 옮기는 사람(브이로그·강의 녹화·게임 녹화 편집), 수 GB 파일을 USB·클라우드 없이 옮기려는 사람, 노트북↔데스크톱 등 PC 두 대를 쓰는 사람, 맥과 윈도우를 같이 쓰는 사람, 아이패드 필기·PDF를 PC로 옮기는 사람, 회의실·스터디·집에서 여러 기기에 한 번에 나눠 주는 상황(이름표로 누가 보냈는지 구분).

## 글 작성 규칙 (blog id lgodl1598, 닉네임 코카곰, 카테고리 front-end)
톤/형식 규칙:
- 사용법 소개, 존댓말, "짧고 굵게". 학교에서 폰과 PC 사이 파일 옮기기가 불편해서 직접 만들었다는 배경은 써도 됨. AI(Claude Code)로 만들었다는 언급은 허용됨.
- 제목은 검색 키워드가 앞에 오고, 뒤에 결과("케이블 없이", "원본 화질 그대로", "5GB까지", "아이폰·갤럭시 다 됨")가 옴.
- 본문 1,500자 내외, 실제 화면 캡처 5~10장, 각 이미지에 한 줄 캡션.
- 반드시 "다른 방법과 비교" 문단 1개 포함 (주제에 맞게: 케이블·카톡 나에게 보내기·구글포토·퀵쉐어·에어드롭·USB·클라우드 드라이브·대용량 전송 사이트 등). 타사 용량·화질 제한 같은 구체 수치는 출처를 확인했을 때만 쓰고, 아니면 수치 없이 쓴다.
- 주제와 맞는 사이트 가이드 페이지가 있으면 본문 중간에 1개 링크(https://www.clipboardapp.org/guide/ 아래, 목록은 https://www.clipboardapp.org/llms.txt 참고). 마지막 단락에는 https://www.clipboardapp.org 링크를 단독 줄로 (OG 카드로 변환됨).
- 지어낸 구체적 에피소드, 확인 안 된 타사 수치는 쓰지 말 것.

캡처 방법 (레이아웃이 바뀌었으므로 예전 "CSS x 476~956 고정 크롭"은 쓰지 말 것):
- https://www.clipboardapp.org 를 열고 마우스를 (5,5)로 옮긴 뒤 page.screenshot 전체 캡처 → 캡처할 요소의 getBoundingClientRect() × devicePixelRatio 로 PIL 크롭. /og-image.png 는 쓰지 말 것.
- 기기 목록·보낸 사람 표시를 보여주려면 탭을 2개 이상 열어 서로 다른 동물 이름표가 생기게 한 뒤 캡처.
- 우선 후보 화면: 연결된 기기 패널(이름표), 업로드 카드("파일당 최대 5GB · 끊겨도 이어서 올려요"), 업로드 진행 카드(취소 버튼), 받은 파일 카드(보낸 기기 표시), 텍스트 탭 입력/공유, 보관·사용 안내, 같은 네트워크/전체 공유 탭, QR 모달.
- 테스트 파일은 브라우저 canvas 등으로 만든 작은 파일(진행 화면이 필요하면 200MB 이하)만 올리고, 캡처 후 사이트에서 삭제. 일일 업로드 한도를 낭비하지 말 것.

주제 순서 (루틴 메모리에 몇 번째까지 썼는지 기록하고 다음 것을 쓸 것. 블로그 목록을 확인해 이미 발행된 글과 중복 금지. 이미 발행: 아이폰 사진 윈도우, PC방, 핸드폰 사진 컴퓨터, 회사 컴퓨터 파일 전송, 폰 PC 텍스트 복사, 학교 컴퓨터 파일 전송):
1. 핸드폰 동영상 컴퓨터로 옮기기, 원본 화질 그대로 (최대 5GB·끊겨도 이어올리기) - 키워드: 핸드폰 동영상 컴퓨터로 옮기기 (서치어드바이저 실제 유입 키워드) - 가이드 phone-video-to-pc-transfer
2. 회원가입 없는 대용량 파일 전송, 같은 와이파이면 5GB까지 - 키워드: 대용량 파일 전송 무료
3. 갤럭시 사진·동영상 맥북으로 옮기기 (퀵쉐어 안 될 때) - 키워드: 갤럭시 사진 맥북으로 옮기기 (2026-09-18 초안이 미발행 상태이니 재활용 가능, 동영상·대용량 내용 보강) - 가이드 galaxy-to-macbook-photo-transfer
4. 컴퓨터에서 컴퓨터로 파일 옮기기, USB 없이 (노트북↔데스크톱) - 키워드: 컴퓨터 파일 옮기기 USB 없이
5. 맥 윈도우 파일 옮기기, 에어드롭 대신 - 키워드: 에어드롭 윈도우 / 맥 윈도우 파일 공유 - 가이드 mac-to-windows-file-transfer
6. 아이폰에 PDF 넣기, 아이튠즈 없이 (윈도우→아이폰) - 키워드: 아이폰 pdf 넣기 (서치어드바이저 실제 유입 키워드) - 가이드 windows-to-iphone-file-transfer
7. 회의실·스터디에서 여러 기기에 파일 한 번에 나눠주기 (이름표로 누가 보냈는지 보임) - 키워드: 여러 기기 파일 공유
8. 아이패드 사진·필기 PDF 윈도우로 옮기기 - 키워드: 아이패드 사진 컴퓨터로 - 가이드 ipad-to-windows-photo-transfer
9. 인쇄하려고 사진 컴퓨터로 보내기 (도서관·프린트 카페) - 키워드: 사진 인쇄 컴퓨터로
10. 폰 인증번호 PC에 바로 붙여넣기 - 키워드: 인증번호 컴퓨터로 - 가이드 copy-verification-code-phone-to-pc
11. PC에서 보던 링크 폰으로 보내기 - 키워드: 컴퓨터 링크 핸드폰으로 보내기 - 가이드 send-link-from-pc-to-phone
12. 카톡 나에게 보내기 대신 쓰는 무료 사이트 (용량·화질 비교) - 키워드: 카톡 나에게 보내기 대신

## 캡처 주의 (2026-10-02 피드백)
- 캡처와 업로드 파일은 반드시 현재 세션의 tmp 폴더에 만든다. 다른 세션 폴더의 파일은 업로드가 "escapes the session directory"로 막힌다.
- 이전 초안 캡처를 재사용해도 되지만, 발행 직전에 라이브 사이트에서 수치(5GB, 보관 기간)를 다시 확인한다.
- 기기 목록이 "Mac 크롬" 두 개로만 보이면 폰↔PC 주제에 설득력이 떨어진다. 두 번째 탭은 모바일 화면 크기·모바일 UA로 열어 폰처럼 보이게 하거나, 그게 안 되면 기기 목록 캡처를 빼고 업로드/수신 카드 위주로 쓴다.
