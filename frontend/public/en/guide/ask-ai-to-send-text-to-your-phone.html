Clipboard Share

Ask an AI assistant to send text to your phone

As of October 2026, the way to get text from an AI chat onto another device is to ask the assistant for a link that starts with https://www.clipboardapp.org/#/send?t= and ends with your text, URL-encoded. Open that link on the receiving device and press Share. That is two steps, with no sign-up and nothing to install.

Devices on the same Wi-Fi connect automatically in the browser. There is no sign-up and no install, files can be up to 5GB each and are kept for about a day at most, you can lock just the files that need it with a password, and a 1:1 room is encrypted automatically. This guide covers the text link only. It describes what the site's code does; it does not mean any particular AI product already supports these links, so you may need to ask the assistant to build the link by hand.

The link format

https://www.clipboardapp.org/#/send?t=<URL-encoded text>

For example, the word "hello" becomes https://www.clipboardapp.org/#/send?t=hello, and a space is written as %20.

  • Opening the link switches to the Text tab and fills the box. A note under it says the text came from a link and asks you to check it and press Share.
  • Nothing is sent automatically. A person, or an agent acting for one, has to press Share.
  • The link can pre-fill up to 20,000 characters. If the box already has text in it, the link does not overwrite it.
  • The link cannot choose the audience. The text goes to whichever scope is selected on screen, Same network or Everyone.
  • The text sits after the #, so it is not part of the page request, and the page removes it from the address bar once it loads. Pressing Share does send the text through the service to the connected devices.

Steps for a person

  1. Tell the assistant which text to send and ask for a link in the format above, with the text URL-encoded.
  2. Open the link in a browser on the device that should receive the text. If getting the link onto the phone is the hard part, open the link on your PC instead and keep https://www.clipboardapp.org/en/ open on the phone.
  3. Check that Share with is set to Same network. Both devices need to be on the same Wi-Fi to see each other.
  4. Read the text in the box, then press Share. The line under the box says "Shared. It now appears in the text list on connected devices." when it worked.
  5. On the other device, open the site, go to the Text tab and tap the item to copy it.

Steps for a browser agent

If you let an agent control your browser, this is the sequence. Keep it to the task you gave it, and tell the user what you are about to press.

  1. Open https://www.clipboardapp.org/#/send?t=….
  2. Check that the Share Text box on the Text tab now contains the text.
  3. Check that Share with matches what the user wanted. If you are unsure, ask, and leave the default Same network alone.
  4. Press Share. The first time you send to Everyone, a confirmation dialog appears.
  5. Read the status line under the box. "Shared…" means success; "Couldn't share. Please try again." means it failed.
  6. For files, use the page's file input, whose accessible name is Choose files. A link cannot attach files.

Keeping it safe

  • The default Same network scope is visible to people behind the same public IP. On a school, office or cafe network that can include other people on that network.
  • For sensitive files, turn on Lock with a password before uploading (at least 4 characters). The file is encrypted in the sending browser and only people with the password can open it.
  • Unlocked text is kept as plain text for 10 minutes and anyone in that scope can see it; it is encrypted only while the password lock is on. Do not send passwords or one-time codes as text over a shared network.
  • To exchange things with one person only, press Connect 1:1 in the device list. After they accept and you both confirm the same pictures, a room for just the two of you opens, and files and text in it are encrypted automatically.
  • The link contains the text itself. Do not leave a link with private text in a chat, a document or a public post.

Questions

Will the assistant send it to my phone by itself?

No. A link only fills in the box, and someone has to press Share. An assistant that can drive your browser can press it for you, if you ask it to.

How long can the text in the link be?

The link pre-fills up to 20,000 characters and cuts anything beyond that. For longer material, save a text file and send it as a file, which can be up to 5GB.

Can a link send a file?

No, a link only pre-fills text. Files go through the Choose files button, or through the file input labeled Choose files if a browser agent is doing the clicking.
