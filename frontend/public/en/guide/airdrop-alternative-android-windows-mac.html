Clipboard Share

An AirDrop Alternative for Android, Windows and Mac

As of October 2026, one way to move files between mixed devices is a browser tab on the same Wi-Fi: no sign-up or install, files up to 5GB each, kept for at most about 1 day. AirDrop only talks to other Apple devices, and Quick Share stops at Android and Windows. The moment you try to move a photo from an Android phone to a Mac, there is nothing between the two.

So people dig out a cable, install a transfer app, or mail the file to themselves. A browser tab skips all three: every device on the same Wi-Fi lands in the same place, whatever brand it is.

How to send a file

  1. Connect both devices to the same Wi-Fi network.
  2. Open https://www.clipboardapp.org/en/ in a browser on each device. They are grouped automatically under the Same network tab, with no code to enter.
  3. On a phone, tap the Upload File card and pick the photos you want to send. On a laptop, drag the files onto the page.
  4. For something already on your clipboard, one paste is enough. On the phone, tap the "Paste" card once and allow clipboard access; whatever you copied (text or an image) is shared right away. On a PC, press Ctrl+V / Cmd+V anywhere on the page.
  5. Tap the item on the receiving device to copy it, or download it to save it. You can select several items and take them all at once.

When another option is better

  • AirDrop: everyone involved has Apple devices and is nearby. Apple's page describes it as sharing with nearby Apple devices.
  • Quick Share: you move files between Android phones and Windows PCs. Google's page covers sending from Android to a Windows laptop and back.
  • LocalSend: you are happy to install an app on every device and want files kept on the device itself, with no internet needed.
  • PairDrop: you want a direct transfer with no database, and the other device is open at the same time.
  • Clipboard Share: you want a phone, a Mac and a PC to connect in the browser with no sign-up or install, and the receiver may open the file later (kept for at most about 1 day).

Good to know

  • On different networks, the Everyone tab still gets the file across, but items there are visible to anyone with the service open. Keep anything private on the same network.
  • Files and text are deleted shortly after every device leaves, so this is a place to hand something over, not to store it.
  • Show a QR code to hand a file to someone else's phone. They point a camera at it instead of typing an address.
  • Add the page to your home screen for an app-like window and a share button in your gallery.

Questions

How is this different from AirDrop or Quick Share?

Those connect devices directly but only inside one ecosystem. This works in the browser, so mixed pairs like Android and Mac behave exactly the same. The trade-off is that files pass through a server, which is why everything is removed once the last device leaves.

Do I need to install anything on the Mac?

No. Safari, Chrome or any current browser is enough, and there is nothing to install on the Android side either. No account, no sign-in.

What is the difference between AirDrop, Quick Share, LocalSend, PairDrop and Clipboard Share?

As of October 2026: AirDrop is for nearby Apple devices, Quick Share covers Android and Windows PCs, LocalSend needs an app on every device, and PairDrop sends directly between devices in a browser. Clipboard Share connects devices on the same Wi-Fi in the browser with no sign-up or install, allows 5GB per file and keeps files for at most about 1 day.
