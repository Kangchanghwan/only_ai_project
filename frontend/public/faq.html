Clipboard Share

자주 묻는 질문

Clipboard Share를 쓰면서 가장 많이 나오는 질문을 모았습니다. 찾는 답이 없다면 사용법 페이지를 먼저 보세요.

시작하기

Clipboard Share는 무엇인가요?

같은 와이파이를 쓰는 기기끼리 사진, 파일, 텍스트를 바로 주고받는 웹 클립보드입니다. 양쪽 기기에서 브라우저로 페이지를 열기만 하면 되고, 한쪽에서 올린 항목이 다른 쪽 화면에 곧바로 나타납니다.

회원가입이나 앱 설치가 필요한가요?

필요 없습니다. 가입도 로그인도 없고 무료입니다. 최신 브라우저가 있으면 아이폰, 안드로이드, 윈도우, 맥 어디서든 똑같이 동작합니다.

연결하려면 코드를 입력해야 하나요?

입력할 코드는 없습니다. 페이지를 열면 같은 공인 IP를 쓰는 기기들이 같은 네트워크 탭에 자동으로 모입니다. 초대하거나 수락하는 단계도 없습니다.

어떤 파일을 보낼 수 있나요?

사진, 문서, 압축 파일 등 형식을 가리지 않습니다. 한 번에 여러 개를 고를 수도 있고, 크기는 업로드 카드에 표시된 최대 용량까지 가능합니다. 그보다 큰 파일은 나눠서 보내거나 압축해 주세요.

앱처럼 홈 화면에 설치할 수 있나요?

네. 브라우저의 홈 화면에 추가를 누르면 앱처럼 열립니다. 설치해 두면 사진 앱이나 브라우저의 공유 버튼에서 곧바로 보낼 수 있어, 페이지를 먼저 열 필요가 없어집니다.

공유와 보안

같은 네트워크와 전체 공유는 어떻게 다른가요?

같은 네트워크 탭은 나와 같은 공인 IP를 쓰는 기기에만 보입니다. 전체 공유 탭은 네트워크와 관계없이 이 서비스를 열어 둔 모든 사람에게 보입니다. 기본값은 항상 같은 네트워크이고, 전체 공유는 직접 탭을 눌러야 켜집니다.

다른 사람 폰에 파일을 건네려면 어떻게 하나요?

QR 코드를 띄우고 상대가 카메라로 찍으면 다운로드 화면이 바로 열립니다. 주소를 불러 주거나 메신저로 링크를 보낼 필요가 없습니다.

올린 파일은 언제 사라지나요?

모든 기기가 페이지를 떠나면 잠시 뒤 파일과 텍스트가 함께 삭제됩니다. 보관용이 아니라 건네주기 위한 자리이니, 받을 파일은 미루지 말고 바로 저장하세요.

전송이 안전한가요?

모든 통신은 HTTPS로 암호화되고, 소스 코드는 GitHub에 공개되어 있습니다. 다만 같은 네트워크에 있는 사람은 같은 항목을 볼 수 있으니, PC방이나 카페처럼 여러 사람이 함께 쓰는 와이파이에서는 민감한 파일을 올리지 않는 편이 좋습니다.

문제 해결

다른 기기가 보이지 않아요.

두 기기가 정말 같은 와이파이에 있는지 확인하세요. 폰이 데이터(LTE)로 연결돼 있거나 회사 네트워크가 기기를 분리해 두면 서로 다른 네트워크로 잡힙니다. 그래도 안 되면 양쪽에서 페이지를 새로고침해 보세요.

붙여넣기가 안 돼요.

폰에서는 화면의 '붙여넣기' 카드를 한 번 탭하고 클립보드 접근을 허용하면 복사해 둔 텍스트나 이미지가 바로 공유됩니다. PC에서는 페이지 어디서나 Ctrl+V / Cmd+V를 누르면 됩니다. 브라우저가 클립보드 접근을 물어볼 때 차단을 눌렀다면, 주소창의 자물쇠 아이콘에서 권한을 다시 허용해 주세요. 그래도 안 되면 파일 업로드 카드로 올리거나, 이미지를 페이지 위로 끌어다 놓으면 됩니다.

파일이 올라가다 멈춰요.

네트워크가 불안정하면 업로드가 끊길 수 있습니다. 새로고침 후 다시 시도하고, 방화벽이 있는 회사망이라면 실시간 연결이 차단되어 있지 않은지 확인해 보세요. 다른 와이파이나 데이터로 바꿔 테스트해 보는 것도 방법입니다.
