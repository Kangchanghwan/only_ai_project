Clipboard Share

Clipboard Share 사용법

같은 와이파이에 있는 기기끼리 사진과 텍스트를 건네는 데 필요한 건 브라우저 탭 하나입니다. 처음 쓰는 사람이 1분 안에 끝낼 수 있도록 순서대로 정리했습니다.

준비

보내는 기기와 받는 기기를 같은 와이파이에 연결한 뒤, 양쪽 브라우저에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크의 기기는 같은 네트워크 탭에 자동으로 묶입니다. 가입, 로그인, 입력할 코드는 없습니다.

파일 보내기

  • PC에서는 파일을 페이지 위로 끌어다 놓거나, 파일 업로드 카드를 눌러 파일을 고릅니다.
  • 폰에서는 파일 업로드 카드를 눌러 사진을 고릅니다. 홈 화면에 추가해 두었다면 사진 앱의 공유 버튼에서 Clipboard Share를 골라 곧바로 보낼 수도 있습니다.
  • 한 번에 여러 개를 골라도 됩니다. 파일 크기는 업로드 카드에 표시된 최대 용량까지 가능합니다.

텍스트 보내기

복사만 해 두면 붙여넣기 한 번으로 넘어갑니다. 폰에서는 화면의 '붙여넣기' 카드를 한 번 탭하고 클립보드 접근을 허용하면 복사해 둔 텍스트나 이미지가 바로 공유됩니다. PC에서는 페이지 어디서나 Ctrl+V / Cmd+V를 누르면 됩니다.

받는 쪽에서는 텍스트 탭에 나타나고, 항목을 누르면 클립보드로 복사됩니다. 링크, 인증번호, 코드 조각처럼 짧게 쓰고 버리는 값을 옮길 때 특히 편하고, 여러 줄 텍스트도 줄바꿈 그대로 도착합니다.

다른 기기에서 받기

  • 올린 항목은 다른 기기 화면에 바로 나타납니다. 새로고침할 필요가 없습니다.
  • 텍스트 항목을 누르면 클립보드로 복사되고, 파일은 다운로드 버튼으로 저장합니다.
  • 여러 개를 선택해 한 번에 받을 수도 있습니다.
  • 다른 사람 폰에 건넬 때는 QR 코드를 띄워 카메라로 찍게 하세요. 상대는 주소를 입력하지 않고 다운로드 화면으로 바로 들어옵니다.

공유 범위

탭이 두 개 있습니다. 같은 네트워크는 나와 같은 공인 IP를 쓰는 기기에만 보이고, 항상 이 탭이 기본값입니다. 전체 공유는 네트워크와 관계없이 이 서비스를 열어 둔 모든 사람에게 보이며, 직접 눌러야 켜집니다.

서로 다른 네트워크에 있는 기기로 보낼 때만 전체 공유를 쓰고, 개인적인 파일이나 인증번호는 같은 네트워크에서만 주고받으세요. PC방이나 카페처럼 여러 사람이 같은 와이파이를 쓰는 곳에서는 같은 네트워크 탭도 옆자리에 보일 수 있습니다.

앱으로 설치

브라우저 메뉴에서 홈 화면에 추가를 누르면 앱처럼 열립니다. 설치해 두면 사진 앱이나 브라우저의 공유 버튼 목록에 나타나서, 페이지를 먼저 열지 않고도 바로 보낼 수 있습니다. 아이폰은 사파리의 공유 버튼, 안드로이드는 크롬 메뉴에서 설정합니다.

팁

  • 모든 기기가 페이지를 떠나면 올려 둔 파일과 텍스트는 곧 삭제됩니다. 받을 파일은 바로 저장하세요.
  • 기기가 서로 보이지 않으면 폰이 데이터(LTE)로 연결돼 있지 않은지 확인하세요. 가장 흔한 원인입니다.
  • 모든 통신은 HTTPS로 암호화되며, 소스 코드는 GitHub에 공개되어 있습니다.
  • 화면 언어는 브라우저 설정을 따라가고, 21개 언어를 지원합니다.
