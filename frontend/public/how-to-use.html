Clipboard Share

Clipboard Share 사용법

같은 와이파이에 있는 기기끼리 사진과 텍스트를 건네는 데 필요한 건 브라우저 탭 하나입니다. 처음 쓰는 사람이 1분 안에 끝낼 수 있도록 순서대로 정리했습니다.

준비

보내는 기기와 받는 기기를 같은 와이파이에 연결한 뒤, 양쪽 브라우저에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크의 기기는 같은 네트워크 탭에 자동으로 묶입니다. 가입, 로그인, 입력할 코드는 없습니다.

46초 영상으로 먼저 보기

아래 순서를 읽기 전에 실제 화면을 먼저 보고 싶다면 이 영상이 빠릅니다. 나레이션 없이 장면마다 제목 한 줄이 붙어 있어서 소리를 꺼도 따라갈 수 있습니다.

  • 0:02 폰에서 사이트를 열면 PC의 기기 목록에 폰의 동물 이름표가 나타납니다. 코드를 입력하거나 QR을 찍는 과정이 없습니다.
  • 0:05 폰의 입력 상자에 쓰고 "공유"를 누르면 PC 목록에 바로 뜹니다.
  • 0:11 폰에서 사진 4장을 고르면 PC 목록에 썸네일과 함께 도착합니다.
  • 0:15 PC에서 "전체 선택" 뒤 "다운로드"를 누르면 4개가 ZIP 하나로 받아집니다.
  • 0:22 PC에서 방을 만들면 그림 4개가 뜹니다. 폰에서 같은 그림을 순서대로 누르고, PC에서 "들이기"를 누르면 폰이 방에 들어옵니다.
  • 0:36 방에 올린 PDF는 파일 이름까지 폰에서 암호화되어 올라가고, PC에서 풀려 원래 이름으로 보입니다.

장면별 표는 영상 페이지에 정리했습니다. 영어판 영상은 유튜브에 있습니다.

파일 보내기

  • PC에서는 파일을 페이지 위로 끌어다 놓거나, 입력 상자 아래 도구 줄의 파일 선택을 눌러 파일을 고릅니다.
  • 폰에서도 파일 선택을 눌러 사진을 고릅니다. 안드로이드는 홈 화면에 추가해 두면 갤러리의 공유 버튼에서 Clipboard Share를 골라 곧바로 보낼 수 있고, 아이폰·아이패드는 단축어를 추가하면 같은 방식으로 보낼 수 있습니다.
  • 한 번에 여러 개를 골라도 됩니다. 파일은 하나에 5GB까지 올릴 수 있고, 연결이 끊겨도 이어서 올립니다.

텍스트 보내기

복사만 해 두면 붙여넣기 한 번으로 넘어갑니다. 폰에서는 입력 상자 아래 도구 줄의 '붙여넣기' 버튼(폰 화면에서는 클립보드 아이콘)을 한 번 누르고 클립보드 접근을 허용하면 복사해 둔 텍스트나 이미지가 바로 공유됩니다. PC에서는 페이지 어디서나 Ctrl+V / Cmd+V를 누르면 됩니다. 직접 쓰는 글은 입력 상자('여기에 입력하거나 파일을 끌어다 놓으세요')에 쓰고 '공유'를 누릅니다.

받는 쪽에서는 목록에 바로 나타나고, 글 오른쪽의 복사를 누르면 클립보드로 복사됩니다. 글 줄을 누르면 긴 글이 펼쳐집니다. 링크, 인증번호, 코드 조각처럼 짧게 쓰고 버리는 값을 옮길 때 특히 편하고, 여러 줄 텍스트도 줄바꿈 그대로 도착합니다.

다른 기기에서 받기

  • 올린 항목은 다른 기기 화면에 바로 나타납니다. 새로고침할 필요가 없습니다.
  • 텍스트는 '복사', 파일은 '받기'를 누릅니다. 이미지는 파일의 ⋯ 메뉴에서 '이미지 복사'로 바로 복사할 수도 있습니다.
  • 여러 파일은 체크해서 고른 뒤 '다운로드'를 누르면 ZIP 하나로 받습니다. 200MB가 넘는 파일은 따로 받습니다.
  • 다른 사람 폰에 건넬 때는 파일의 ⋯ 메뉴에서 'QR 코드로 공유'를 골라 카메라로 찍게 하세요. 상대는 주소를 입력하지 않고 그 파일을 받는 화면으로 바로 들어옵니다.
  • 보낸 글을 지우려면 글 오른쪽의 ⋯ 메뉴를 엽니다. 보관 중인 10분 동안 내가 보낸 글에는 보관 취소가 보이고, 누르면 서버 보관함에서 지워져 다른 기기 목록에서도 사라집니다. 같은 메뉴의 삭제는 글 하나를, 목록 위 모든 텍스트 삭제는 지금 탭의 글을 한꺼번에 지웁니다. 이 두 가지는 지운 뒤 5초 동안 실행 취소로 되돌릴 수 있습니다.

같은 네트워크·전체 공유 탭

탭이 두 개 있습니다. 같은 네트워크는 나와 같은 공인 IP를 쓰는 기기에만 보이고, 항상 이 탭이 기본값입니다. 전체 공유는 네트워크와 관계없이 이 서비스를 열어 둔 모든 사람에게 보이며, 직접 눌러야 켜집니다.

개인적인 파일이나 인증번호는 전체 공유로 보내지 마세요. 서로 다른 네트워크에 있는 기기와 주고받을 때는 방을 만들어 초대하는 편이 안전합니다. PC방이나 카페처럼 여러 사람이 같은 와이파이를 쓰는 곳에서는 같은 네트워크 탭도 옆자리에 보일 수 있습니다.

휴대폰을 QR로 연결하기

폰에서 주소를 입력하지 않고, PC 화면의 QR을 폰 카메라로 찍어 연결할 수 있습니다. QR을 띄우는 버튼은 PC에서 보고 있는 탭에 따라 이름이 다릅니다.

  • 같은 네트워크 탭: 기기 카드 줄의 휴대폰 초대 버튼(점선 카드)을 누르면 QR 창이 열립니다. 창에 "폰 카메라로 찍으면 바로 연결돼요. 다른 네트워크의 휴대폰이면 연결 요청이 와요"라고 나옵니다. 화면이 넓으면 이 버튼이 카드 목록 위쪽 제목 줄 오른쪽 끝에 있고, 좁으면 카드 줄의 두 번째 점선 카드입니다.
  • 전체 공유 탭: 같은 자리에 휴대폰에서 열기 버튼이 있고, 누르면 QR 창에 "찍으면 전체 공유가 바로 열려요. 전체 공유는 모든 사용자가 볼 수 있어요"라고 나옵니다.
  • 방 탭: 방 이름 줄의 초대를 누르면 그림, QR, 링크 중에서 고를 수 있습니다. 자세한 내용은 아래 방 절을 보세요.

같은 네트워크 탭의 QR은 5분마다 새 것으로 바뀌고 길어도 10분까지만 쓸 수 있으며, 처리하지 않은 연결 요청이 3건을 넘으면 더 받지 않습니다. 믿는 사람에게만 화면을 보여 주세요.

민감한 파일은 비밀번호로 잠그기

신분증 사진, 계약서, 증명서처럼 남이 보면 곤란한 파일은 보내기 전에 잠가 두세요. 같은 네트워크나 전체 공유 탭에서 비밀번호로 잠그기를 누르고 4자 이상 비밀번호를 정한 뒤 파일을 올리면 됩니다. 잠금은 직접 켜야 하고, 켜 둔 동안 그 탭으로 보내는 파일에만 적용됩니다.

  • 파일 이름과 내용은 보내는 기기의 브라우저에서 암호화된 뒤 올라갑니다. 비밀번호는 서버로 보내지 않으니, 받는 사람에게는 따로 알려 주세요.
  • 받는 쪽에는 이름이 가려진 잠긴 파일로 보입니다. 풀기를 누르고 같은 비밀번호를 넣으면 그 기기에서 풀어 저장합니다. 틀릴 수 있는 횟수는 정해져 있습니다.
  • 잠긴 파일의 ⋯ 메뉴에서 QR 코드로 공유를 고르면, QR을 찍은 사람은 비밀번호 없이 그 파일 하나를 받습니다. QR 화면은 받을 사람에게만 보여 주세요.
  • 기기 이름과 파일 크기는 잠기지 않습니다. 텍스트는 잠금을 켠 동안 보낸 것만 암호화되고, 잠그지 않은 텍스트는 10분 동안 평문으로 보관됩니다. 비밀번호를 잊으면 되찾을 방법이 없습니다.

화면과 함께 본 순서는 파일 비밀번호 걸어서 보내기에 정리했습니다.

방: 다른 네트워크의 기기와 암호화해서 주고받기

방은 들어온 기기끼리만 보는 공간입니다. 같은 와이파이가 아니어도 연결되고, 방 안에서 주고받는 파일과 텍스트는 비밀번호를 정하지 않아도 이 기기에서 자동으로 암호화됩니다(방 안에서의 종단간 암호화). 들어간 방은 위쪽 탭 줄에 방 이름으로 보입니다. 방 탭에서는 입력 상자 아래 도구 줄에 '비밀번호로 잠그기' 대신 '끌어다 놓아도 자동으로 암호화돼요'(폰 화면에서는 자물쇠 아이콘)가 보이니, 따로 잠글 필요가 없습니다.

방 만들기

  • 기기 목록에 상대 기기가 보이면 그 기기의 방으로 연결을 누릅니다. 상대가 수락하고 두 화면에 뜬 그림 4개가 같은지 서로 확인하면 둘이 쓰는 방이 열립니다. 그림이 다르면 거절하세요.
  • 상대가 기기 목록에 없으면(폰이 데이터로 연결돼 있거나 다른 와이파이에 있을 때) 탭 줄의 ＋ 방을 누르고 새 방 만들기를 고릅니다. 그다음 아래처럼 다른 기기를 초대합니다.

다른 기기 초대하기

방의 초대를 누르면 그림, QR, 링크 중에서 고를 수 있습니다.

  • QR·링크: 새 기기에서 QR을 찍거나 링크를 열면 입장 확인 창이 뜨고, 확인하면 방에 들어옵니다. 10분 동안 쓸 수 있고 그동안은 QR이나 링크를 가진 사람 누구나 들어올 수 있으니, 믿는 사람에게만 보여 주세요.
  • 그림: 새 기기에서 ＋ 방 → 그림으로 들어가기를 누르고, 방에 있는 기기 화면의 그림 4개를 순서대로 누릅니다. 그림을 맞게 눌러도 방에 있는 기기에서 들이기를 눌러야 들어옵니다. 카메라로 QR을 찍기 어려운 PC끼리 쓸 때 편합니다.

상대가 잠시 나가 있어도 방에 올린 파일은 최대 약 1일 보관되어, 다시 들어오면 받을 수 있습니다. 텍스트는 10분 동안 보관됩니다.

방 파일 수정하기

방에 올린 한글(hwp, hwpx)과 오피스(docx, xlsx, pptx, doc, xls, ppt, pdf) 파일은 다운로드하지 않고 방 위에 열리는 편집기에서 바로 고칠 수 있습니다.

  • 파일 줄의 ⋯ 메뉴에서 수정을 누르거나 파일 이름을 누르면 편집기가 열립니다. PC 화면에서만 쓸 수 있고, 폰 화면에서는 보이지 않습니다.
  • 편집기 오른쪽 위의 저장 ▾를 누르면 저장 (원본 덮어쓰기)가 나옵니다. 누르면 방에 있던 그 파일이 고친 내용으로 바뀝니다. 편집기 안에서 Ctrl+S / Cmd+S를 누르면 메뉴 없이 바로 저장합니다. 컴퓨터로 받고 싶으면 같은 메뉴의 내려받기를 쓰고, 한글 파일은 HWPX로 내려받기와 HWP로 내려받기가 나옵니다. 오른쪽 위 ✕로 닫습니다.
  • 비밀번호로 잠근 파일은 수정해도 잠긴 채로 저장됩니다. 잠그지 않은 파일을 잠그지는 않습니다. doc, ppt 같은 옛 형식은 저장하면 새 형식(docx, pptx)으로 바뀔 수 있고, 이때 방의 원본은 지워집니다.

편집기는 문서를 다시 만들어 저장하기 때문에 글꼴, 표, 줄 간격 같은 서식이 일부 달라질 수 있습니다. 저장은 방에 있는 복사본만 덮어쓰고, 원본은 처음 올린 기기에 그대로 남아 있으니 중요한 문서는 원본을 따로 보관하세요.

무엇이 암호화되고, 서버는 무엇을 보나요

  • 방에 올린 파일은 파일 이름과 내용이 이 기기에서 방 열쇠로 암호화된 뒤 올라갑니다. 방 텍스트도 암호화해서 보내고, 서버는 암호문만 10분 동안 보관합니다.
  • 방 열쇠는 서버로 가지 않습니다. 방으로 연결할 때는 두 화면의 그림으로 확인한 연결로, QR·링크는 주소의 # 뒤(서버 요청에 실리지 않는 부분)에 담아, 그림 초대는 그림 4개를 비밀번호처럼 쓰는 방식으로 넘깁니다.
  • 서버가 보는 것: 파일 크기, 올린 시각, 기기 이름표, 어느 기기가 어느 방에 있는지, 접속 IP.
  • 같은 네트워크와 전체 공유 탭은 방이 아닙니다. 이 두 탭에서는 비밀번호로 잠그기를 켰을 때만 암호화됩니다.
  • 웹앱이라 사이트가 내려주는 코드를 믿고 쓰는 구조이고, 그 코드는 GitHub에 공개되어 있습니다. 브라우저 데이터를 지우면 방 열쇠도 사라져 그 방에 다시 들어갈 수 없고, 들어온 기기를 내보내는 기능은 아직 없습니다.

앱으로 설치

브라우저 메뉴에서 홈 화면에 추가를 누르면 앱처럼 열립니다. 아이폰은 사파리의 공유 버튼, 안드로이드는 크롬 메뉴에서 추가합니다. 안드로이드는 이렇게 설치해 두면 갤러리나 파일 앱의 공유 버튼 목록에 Clipboard Share가 나타납니다. 아이폰·아이패드는 홈 화면에 추가해도 공유 목록에는 나타나지 않으니, 아래 단축어를 쓰세요.

아이폰·아이패드: 공유 메뉴에서 바로 보내기

사진 앱이나 파일 앱에서 공유 버튼을 누르고 단축어를 고르면, 사이트를 열지 않고도 같은 와이파이의 PC로 바로 보냅니다. 단축어는 아이폰·아이패드에 기본으로 들어 있는 앱이고, 아래 링크에서 단축어 추가를 한 번 누르면 설치가 끝납니다.

  • Clipboard Share로 파일 보내기: 사진, 동영상, 파일, PDF. 여러 개를 골라도 한 번에 보냅니다.
  • Clipboard Share로 텍스트 보내기: 공유한 텍스트나 링크를 보냅니다. 공유 없이 단축어를 그냥 실행하면 복사해 둔 클립보드 내용을 보냅니다.
  1. 사진 앱이나 파일 앱에서 보낼 항목을 고르고 공유 버튼을 누릅니다.
  2. 목록 아래쪽 동작 중에서 Clipboard Share로 파일 보내기를 누릅니다. 자주 쓰면 동작 편집에서 즐겨찾기에 올려 두세요.
  3. 처음 한 번은 api.clipboardapp.org로 보내도 되는지 묻습니다. 항상 허용을 누르면 다음부터는 묻지 않습니다.
  4. 끝나면 "파일 N개를 보냈어요" 알림이 뜨고, 같은 와이파이에서 clipboardapp.org를 열어 둔 PC 화면에 바로 나타납니다. 보낼 때 PC가 닫혀 있었다면 보관 시간 안에 열면 보입니다.

단축어로 보낸 항목은 같은 네트워크 탭으로만 갑니다. 폰이 데이터(LTE)로 연결돼 있으면 PC와 네트워크가 달라 보이지 않으니 와이파이를 켜 두세요. 파일은 하나에 95MB까지 보낼 수 있고, 더 큰 동영상은 사이트에서 올려 주세요. 단축어로 보낸 파일과 텍스트는 비밀번호로 잠기지 않습니다. 파일은 최대 1일, 텍스트는 10분 동안 보관되고, 그동안 같은 네트워크의 다른 사람에게도 보일 수 있습니다.

자주 묻는 질문

서버가 내 파일을 볼 수 있나요?

방에서 보낸 파일과 텍스트는 이 기기에서 암호화되어 서버에는 암호문만 있습니다. 같은 네트워크·전체 공유 탭은 '비밀번호로 잠그기'를 켰을 때만 암호화됩니다. 파일 크기와 기기 이름표는 서버가 봅니다.

다른 와이파이나 데이터를 쓰는 기기와는 어떻게 주고받나요?

방을 만들어 초대하세요. 탭 줄의 '＋ 방'에서 새 방을 만든 뒤 '초대'의 QR이나 링크를 다른 기기에서 열면 같은 방에 들어옵니다. 전체 공유 탭은 이 서비스를 연 모든 사람에게 보이니 개인 파일에는 쓰지 마세요.

팁

  • 모든 기기가 페이지를 떠나면 올려 둔 파일과 텍스트는 곧 삭제됩니다. 받을 파일은 바로 저장하세요.
  • 기기가 서로 보이지 않으면 폰이 데이터(LTE)로 연결돼 있지 않은지 확인하세요. 가장 흔한 원인입니다.
  • 모든 통신은 HTTPS로 암호화되며, 소스 코드는 GitHub에 공개되어 있습니다.
  • 화면 언어는 브라우저 설정을 따라가고, 21개 언어를 지원합니다.
