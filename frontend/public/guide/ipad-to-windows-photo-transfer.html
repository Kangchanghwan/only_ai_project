아이패드 사진, 윈도우 PC로 케이블 없이 옮기기

아이패드로 그린 그림이나 필기 앱에서 내보낸 PDF, 수업 중 찍은 스크린샷을 윈도우 PC로 가져오려면 케이블을 꽂고 탐색기에서 DCIM 폴더를 뒤지거나, 아이클라우드 웹에 로그인해 한 장씩 내려받게 됩니다. 아이패드 케이블은 충전기에 꽂혀 있을 때가 많고, 윈도우에서는 HEIC 사진이 열리지 않아 한 번 더 막힙니다.

아이패드와 PC를 같은 와이파이에 두고 브라우저를 열면 그 과정이 사라집니다. 아이패드에서 올린 파일이 몇 초 뒤 PC 화면에 나타나고, 설치할 앱도 만들 계정도 없습니다.

옮기는 방법

  1. 아이패드와 윈도우 PC를 같은 와이파이에 연결합니다. 유선으로 연결된 PC라도 같은 공유기에 물려 있으면 됩니다.
  2. 양쪽 기기의 브라우저에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크에 있는 기기는 같은 네트워크 탭에 자동으로 함께 묶입니다. 입력할 코드도, 눌러야 할 초대 버튼도 없습니다.
  3. 아이패드의 사파리에서 파일 업로드 카드를 누르면 사진 앱 또는 파일 앱을 고를 수 있습니다. 사진은 여러 장을 한 번에 선택해도 되고, 굿노트나 프로크리에이트에서 내보낸 PDF나 이미지는 파일 앱에서 고르면 됩니다.
  4. 방금 찍은 스크린샷처럼 이미 복사해 둔 것이 있다면 붙여넣기 카드를 한 번 탭하고 클립보드 접근을 허용하세요. 사진 앱을 열 필요 없이 바로 올라갑니다.
  5. PC 화면에 항목이 바로 나타납니다. 다운로드 버튼으로 저장하거나, 항목을 눌러 클립보드에 복사한 뒤 문서에 바로 붙여넣으세요.
  6. 반대 방향도 같습니다. PC에서 파일을 페이지 위로 끌어다 놓거나 Ctrl+V로 붙여넣으면 아이패드 화면에 나타납니다.

알아두면 좋은 것

  • 아이패드 사진이 HEIC 형식이라 윈도우에서 열리지 않는다면, 설정의 카메라에서 형식을 호환성 우선으로 바꾸거나 사진 앱에서 공유할 때 JPEG로 내보내세요. 전송 자체는 형식에 상관없이 그대로 됩니다.
  • 스플릿 뷰로 사파리와 사진 앱을 나란히 열어 두면 사진을 페이지 위로 끌어다 놓는 것도 됩니다.
  • 두 기기가 다른 네트워크에 있다면 전체 공유 탭을 쓸 수 있지만, 이 탭의 항목은 서비스를 열어 둔 모든 사람에게 보입니다. 남에게 보이면 곤란한 파일은 같은 네트워크에서만 주고받으세요.
  • 모든 기기가 페이지를 닫으면 올려 둔 파일과 텍스트는 곧 삭제됩니다. 받을 파일은 미루지 말고 바로 저장하는 편이 좋습니다.

자주 묻는 질문

아이클라우드나 애플 계정이 필요한가요?

필요 없습니다. 브라우저만 있으면 되고 어떤 계정으로도 로그인하지 않습니다. 윈도우 PC에 아이튠즈나 아이클라우드를 설치하지 않아도 됩니다.

필기 앱에서 내보낸 PDF도 되나요?

됩니다. 사진뿐 아니라 PDF, 문서, 압축 파일 등 어떤 파일이든 100MB까지 그대로 전달됩니다. 파일 업로드 카드에서 파일 앱을 선택해 고르면 됩니다.

사진 화질이 떨어지지 않나요?

메신저처럼 자동으로 압축하지 않고 원본 파일을 그대로 전달합니다.
