Clipboard Share

대용량 파일, 회원가입 없이 무료로 보내기

메일에 첨부하려니 용량 제한에 걸리고, 메신저로 보내자니 동영상은 압축되고 큰 파일은 아예 안 올라갑니다. 클라우드 드라이브는 로그인하고, 올리고, 공유 링크를 만들고, 받는 쪽에서 다시 로그인하는 과정이 번거롭습니다.

보내는 기기와 받는 기기가 같은 와이파이에 있다면 더 간단합니다. 두 기기에서 브라우저로 사이트를 열기만 하면 자동으로 연결되고, 한 파일에 5GB까지 원본 그대로 넘어갑니다. 가입도, 앱 설치도, 결제도 없습니다.

보내는 방법

  1. 보내는 기기와 받는 기기를 같은 와이파이(같은 공유기)에 연결합니다. 폰과 PC, PC와 PC, 폰과 태블릿 모두 됩니다.
  2. 두 기기의 브라우저에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크에 있는 기기는 같은 네트워크 탭에 자동으로 묶입니다. 가입, 로그인, 6자리 코드 입력이 없습니다.
  3. 보내는 쪽에서 파일 업로드 카드를 누르고 파일을 고릅니다. 여러 개를 한 번에 골라도 됩니다. 한 파일은 5GB까지 올라가고, 진행률이 표시되며 ✕로 취소할 수 있습니다.
  4. 받는 기기 화면에 파일이 나타나면 다운로드 버튼으로 저장합니다. 파일은 최대 1일 안에 자동 정리되니 바로 받아 두세요.

이럴 때 쓰기 좋습니다

  • 폰으로 찍은 긴 동영상이나 사진 수백 장을 PC로 옮길 때 (메신저처럼 압축되지 않습니다)
  • 회사·학교 PC에 개인 계정으로 로그인하기 싫을 때
  • 맥과 윈도우, 아이폰과 갤럭시처럼 기종이 달라 AirDrop이나 퀵쉐어가 안 될 때
  • 설계 파일, 압축 파일, 영상 편집 원본처럼 메일 첨부 한도를 넘는 파일을 옆자리 PC로 넘길 때

알아두면 좋은 것

  • 전송 속도는 와이파이 환경에 따라 달라집니다. 큰 파일을 올리는 동안에는 폰 화면이 꺼지지 않게 두세요. 끊기면 같은 파일을 다시 고르면 이어서 올라갑니다.
  • 학교·회사처럼 같은 네트워크를 여러 사람이 쓰는 곳에서는 같은 네트워크 탭의 항목이 다른 사람에게도 보일 수 있습니다. 민감한 파일은 받은 뒤 바로 삭제하세요.
  • 수십 GB 단위의 백업이라면 외장 저장장치나 케이블이 더 적합합니다.

자주 묻는 질문

정말 무료이고 가입이 필요 없나요?

네. 계정이 없고 결제 기능도 없습니다. 브라우저에서 사이트를 열면 바로 쓸 수 있고, 앱을 설치할 필요도 없습니다.

최대 몇 GB까지 보낼 수 있나요?

한 파일에 5GB, 한 룸에 합계 10GB까지입니다. 100MB가 넘는 파일은 조각으로 나눠 올리기 때문에 중간에 연결이 끊겨도 같은 파일을 다시 고르면 이어서 올라갑니다. 5GB를 넘는 파일은 압축 프로그램으로 분할해서 보내 주세요.

보낸 파일은 언제 지워지나요?

모든 기기가 페이지를 닫으면 잠시 후 삭제되고, 접속 중이어도 최대 1일 안에 자동으로 정리됩니다. 오래 보관하는 용도가 아니라 지금 옮기는 용도입니다.

다른 장소에 있는 사람에게도 보낼 수 있나요?

전체 공유 탭을 쓰면 네트워크가 달라도 주고받을 수 있지만, 이 탭의 항목은 서비스를 열어 둔 모든 사람에게 보입니다. 개인 파일은 같은 네트워크 탭에서만 주고받는 것을 권합니다.
