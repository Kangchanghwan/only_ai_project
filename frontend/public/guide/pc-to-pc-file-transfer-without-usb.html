Clipboard Share

컴퓨터에서 컴퓨터로 파일 옮기기, USB 없이

노트북에서 만든 파일을 데스크톱으로, 예전 PC의 사진 폴더를 새 PC로 옮기려는데 USB 메모리가 안 보일 때가 있습니다. 메일에 첨부하자니 용량이 걸리고, 클라우드는 양쪽 PC에 로그인해야 하고, 윈도우 공유 폴더는 설정할 게 많습니다.

두 컴퓨터가 같은 공유기에 연결돼 있다면 브라우저만으로 끝납니다. 양쪽에서 사이트를 열면 자동으로 연결되고, 파일을 끌어다 놓으면 상대 PC 화면에 바로 나타납니다. 가입도, 프로그램 설치도 없습니다.

옮기는 방법

  1. 노트북은 와이파이로, 데스크톱은 랜선으로 연결돼 있어도 같은 공유기를 쓰면 됩니다. 윈도우와 맥, 윈도우와 윈도우 모두 됩니다.
  2. 두 PC의 브라우저(크롬, 엣지, 사파리, 웨일)에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크에 있는 PC는 같은 네트워크 탭에 자동으로 묶이고, 왼쪽 연결된 기기 목록에 상대 PC가 동물 이름표로 보입니다.
  3. 파일 업로드 카드에 파일을 끌어다 놓거나 눌러서 고릅니다. 여러 개를 한 번에 올려도 되고, 한 파일은 5GB까지 올라갑니다. 진행률이 보이고 ✕로 취소할 수 있습니다.
  4. 받는 PC 화면에 파일이 어느 기기에서 왔는지와 함께 나타납니다. 다운로드 버튼으로 저장하세요. 파일은 최대 1일 안에 자동 정리되니 바로 받아 두는 것이 좋습니다.

다른 방법과 비교

  • USB 메모리·외장하드: 수십 GB 이상 한꺼번에 옮길 때는 여전히 가장 확실합니다. 다만 메모리를 찾고, 꽂고, 복사하고, 다시 꽂는 과정이 필요합니다.
  • 윈도우 공유 폴더: 같은 집 PC끼리 매일 파일을 주고받는다면 좋습니다. 처음 한 번 계정·권한·네트워크 검색 설정을 맞춰야 하고, 맥과 섞이면 더 번거롭습니다.
  • 클라우드 드라이브: 다른 장소로 보낼 때 편하지만, 두 PC 모두 같은 계정으로 로그인해야 하고 업로드가 끝난 뒤 다시 내려받아야 합니다.
  • Clipboard Share: 지금 옆에 있는 PC로 파일 몇 개를 바로 넘길 때 빠릅니다. 설정과 로그인이 없고, 한 파일 5GB까지 됩니다. 보관용이 아니라 최대 1일 안에 지워집니다.

이럴 때 쓰기 좋습니다

  • 노트북으로 작업한 문서·영상 편집 파일을 집 데스크톱에서 이어서 할 때
  • 새 PC를 샀는데 예전 PC에서 사진 폴더, 설치 파일 몇 개만 먼저 옮기고 싶을 때
  • 맥북과 윈도우 데스크톱을 같이 써서 에어드롭이 안 될 때
  • 사무실 옆자리 PC로 메신저 용량 제한에 걸리는 파일을 넘길 때

알아두면 좋은 것

  • 폴더는 압축해서 한 파일로 올리면 받는 쪽에서 한 번에 내려받을 수 있습니다.
  • 회사·학교처럼 같은 네트워크를 여러 사람이 쓰는 곳에서는 같은 네트워크 탭의 항목이 다른 사람에게도 보일 수 있습니다. 민감한 파일은 받은 뒤 바로 삭제하세요.
  • 전체 공유 탭은 서비스를 열어 둔 모든 사람에게 보이므로 개인 파일에는 쓰지 마세요.

자주 묻는 질문

공유 폴더(네트워크 드라이브) 설정이 필요한가요?

아니요. 윈도우 공유 폴더처럼 사용자 계정, 권한, 방화벽을 설정할 필요가 없습니다. 두 PC에서 브라우저로 같은 사이트를 열면 끝입니다. 매일 같은 폴더를 계속 동기화해야 한다면 공유 폴더나 동기화 프로그램이 더 맞습니다.

노트북은 와이파이, 데스크톱은 유선이어도 되나요?

집처럼 둘 다 같은 공유기에 붙어 있으면 됩니다. 회사·학교는 유선망과 와이파이가 서로 다른 인터넷 출구를 쓰는 경우가 있어서, 그때는 같은 네트워크 탭에 상대 PC가 보이지 않을 수 있습니다. 그럴 땐 두 PC를 같은 와이파이에 연결해 보세요.

몇 GB까지 옮길 수 있나요?

한 파일에 5GB, 한 룸에 합계 10GB까지입니다. 100MB가 넘는 파일은 조각으로 나눠 올리므로 중간에 연결이 끊겨도 같은 파일을 다시 고르면 이어서 올라갑니다. 폴더 통째로는 압축해서 한 파일로 올리면 편합니다.

새 PC로 전체 데이터를 이사할 때도 쓸 수 있나요?

수십 GB가 넘는 전체 이사에는 외장 저장장치나 운영체제의 이전 도구가 더 적합합니다. 이 방법은 작업 파일, 사진 폴더, 설치 파일처럼 지금 당장 몇 개를 옮길 때 빠릅니다.
