폰에서 복사한 텍스트, PC에 바로 붙여넣기

폰으로 받은 링크나 인증번호를 PC에 옮기려고 나에게 메시지를 보내 본 적이 있을 겁니다. 몇 글자 때문에 메신저를 열고, 대화방에는 부스러기 같은 메시지가 쌓입니다.

한쪽에서 붙여넣으면 다른 쪽에서 바로 복사되는 자리가 있으면 그걸로 끝납니다. 브라우저 탭 하나면 되고, 긴 URL을 눈으로 옮겨 적을 일도 없습니다.

옮기는 방법

  1. 폰과 PC를 같은 와이파이에 연결하고, 양쪽에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크의 기기는 같은 네트워크 탭에 자동으로 모입니다.
  2. 폰에서 보낼 텍스트를 평소처럼 복사합니다. 링크든 인증번호든 상관없습니다.
  3. 폰에서는 화면의 '붙여넣기' 카드를 한 번 탭하고 클립보드 접근을 허용하면 복사해 둔 텍스트나 이미지가 바로 공유됩니다. PC에서는 페이지 어디서나 Ctrl+V / Cmd+V를 누르면 됩니다.
  4. PC 화면의 텍스트 탭에 같은 내용이 바로 나타납니다. 항목을 클릭하면 클립보드로 복사되니 어디든 붙여넣으면 됩니다.
  5. 반대 방향도 같습니다. PC에서 Ctrl+V / Cmd+V를 누르면 폰의 텍스트 탭에 나타나고, 탭하면 복사됩니다.

알아두면 좋은 것

  • 인증번호처럼 짧게 쓰고 버리는 값은 같은 네트워크 탭에서만 주고받으세요. 전체 공유 탭은 서비스를 열어 둔 모든 사람에게 보입니다.
  • 계정 비밀번호나 카드번호는 어느 탭에서도 보내지 않는 편이 좋습니다. 잠깐 머무는 자리지 금고가 아닙니다.
  • 모든 기기가 페이지를 떠나면 보낸 텍스트도 곧 삭제됩니다. 나중에 다시 볼 내용이라면 메모 앱에 옮겨 두세요.
  • 홈 화면에 추가해 두면 앱처럼 열리고, 다른 앱의 공유 버튼에서 바로 보낼 수 있습니다.

자주 묻는 질문

폰 클립보드가 자동으로 동기화되나요?

아닙니다. 붙여넣기 카드를 탭한 그 순간의 클립보드 내용만 건너갑니다. 브라우저가 사용자 몰래 클립보드를 들여다보지 않기 때문에, 보낼 때마다 직접 허락하는 이 방식이 오히려 마음이 편합니다.

긴 코드나 여러 줄 텍스트도 되나요?

됩니다. 줄바꿈이 있는 코드 조각이나 주소 여러 개를 한 번에 보내도 그대로 도착합니다. 받는 쪽에서 항목을 누르면 전체가 클립보드로 복사됩니다.
