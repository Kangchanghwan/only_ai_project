Clipboard Share

파일에 비밀번호 걸어서 보내기, 가입 없이 브라우저에서

신분증 사진, 계약서, 재직·졸업 증명서, 이력서처럼 남이 보면 곤란한 파일을 옮겨야 할 때가 있습니다. PC방·도서관·학교·회사의 공용 PC나, 여러 사람이 같은 와이파이를 쓰는 곳이라면 더 그렇습니다. 메신저에 로그인하자니 공용 PC에 계정이 남을까 걱정되고, 압축 파일에 암호를 걸자니 받는 쪽에도 압축 프로그램이 있어야 합니다.

Clipboard Share에서는 보낼 파일만 골라 비밀번호로 잠글 수 있습니다. 파일 이름과 내용은 보내는 기기의 브라우저에서 암호화된 뒤 올라가고, 같은 비밀번호를 아는 사람만 열 수 있습니다. 가입도 앱 설치도 없고, 같은 와이파이의 기기는 코드 입력 없이 자동으로 연결됩니다.

이럴 때 쓰세요

  • 공용 PC에서 신분증·서류 사진을 출력하거나 제출 사이트에 올려야 할 때
  • 학교·회사·카페처럼 같은 네트워크를 여러 사람이 쓰는 곳에서 내 파일만 따로 보내고 싶을 때
  • 다른 네트워크에 있는 사람에게 '전체 공유'로 보내야 하는데 아무나 열면 안 되는 파일일 때

잠가서 보내는 방법

  1. 잠금 켜기. 보내는 기기에서 https://www.clipboardapp.org/ 를 열고, 파일 업로드 카드 아래 "비밀번호로 잠그기"를 누릅니다. 4자 이상 비밀번호를 넣고 "잠금 켜기"를 누르면 "잠금 켜짐"으로 바뀝니다.
  2. 파일 올리기. 평소처럼 파일을 고르거나 끌어다 놓습니다. 잠금이 켜져 있는 동안 이 탭으로 보내는 파일은 이 기기에서 잠근 뒤 올라갑니다. 다 보냈으면 "해제"를 눌러 잠금을 끕니다.
  3. 비밀번호 따로 알려 주기. 받는 사람에게 비밀번호를 말로 전하거나 다른 경로로 알려 줍니다. 받는 화면에는 파일 이름 대신 알아볼 수 없는 문자열과 자물쇠 표시만 보입니다.
  4. 받는 쪽에서 풀기. 받는 기기에서 같은 사이트를 열고 잠긴 파일의 "풀기"를 누른 뒤 비밀번호를 넣습니다. 그 기기에서 풀리면서 원래 이름으로 저장됩니다. 비밀번호를 여러 번 틀리면 그 파일은 더 받을 수 없습니다.
  5. QR로 넘기기 (선택). 비밀번호를 입력하기 번거로우면 보낸 기기에서 파일의 "⋯" 버튼 → "QR 코드로 공유"를 누르고, 받는 폰으로 QR을 찍게 합니다. QR에는 그 파일 하나의 열쇠가 들어 있어 비밀번호 없이 받습니다.

잠기는 것과 잠기지 않는 것

잠기는 것

  • 파일 내용과 파일 이름. 받는 화면에는 원래 이름 대신 알아볼 수 없는 문자열이 보입니다.
  • 비밀번호는 PBKDF2-SHA256(60만 회)으로 열쇠를 만들고, 파일마다 새로 만든 무작위 열쇠로 AES-GCM 암호화합니다. 서버에는 암호문과 비밀번호 확인값만 갑니다.
  • 잠금을 켠 동안 텍스트 탭으로 보낸 글. 받을 기기가 없어도 10분 동안 암호문으로 보관됩니다.

잠기지 않는 것

  • 기기 이름표(동물 이름)와 기기·브라우저 정보
  • 파일 크기와 보낸 시간

잠금은 자동으로 켜지지 않습니다. 보낼 때마다 직접 켜야 하고, 잠긴 파일은 미리보기·썸네일·여러 개 한 번에 받기가 없습니다.

알아두면 좋은 것

  • 비밀번호는 받는 사람에게 같은 화면이 아닌 다른 경로(말, 전화, 문자)로 알려 주세요.
  • '전체 공유' 탭에서 처음 보낼 때 뜨는 확인 창에도 선택 비밀번호 칸이 있습니다. 비워 두면 잠그지 않고 보냅니다.
  • 기기에 따라 아주 큰 잠긴 파일은 휴대폰 브라우저에서 풀지 못한다는 안내가 나올 수 있습니다. 그때는 PC나 안드로이드 크롬에서 받으세요.
  • 받은 뒤에는 공용 PC의 다운로드 폴더에서 파일을 지우고, 사이트에서도 "⋯" → 삭제를 눌러 두면 더 깔끔합니다.

다른 방법과 비교

압축 프로그램으로 암호를 거는 방법은 익숙하지만, 보내는 쪽과 받는 쪽 모두 압축 프로그램이 있어야 하고 파일을 옮길 통로(메일, 메신저, USB)는 따로 필요합니다. PairDrop·Snapdrop 같은 브라우저 직접 전송은 두 기기가 동시에 켜져 있어야 합니다. 여기서는 같은 와이파이면 자동으로 연결되고, 받는 사람이 조금 뒤에 열어도 되며(최대 약 1일), 필요한 파일만 골라 잠그고, 비밀번호 대신 QR로 넘길 수도 있습니다.

자주 묻는 질문

운영자나 같은 와이파이의 다른 사람이 파일을 볼 수 있나요?

잠근 파일은 보내는 기기의 브라우저에서 이름과 내용을 암호화한 뒤 올라가고, 서버에는 암호문과 비밀번호 확인값만 저장됩니다. 비밀번호와 열쇠는 서버로 보내지 않습니다. 같은 네트워크의 다른 사람에게는 잠긴 파일이 있다는 것, 크기, 보낸 시간, 보낸 기기의 이름표만 보입니다.

텍스트도 잠글 수 있나요?

네. 잠금을 켠 범위로 보낸 텍스트도 이 기기에서 암호화되어 비밀번호를 아는 기기에서만 내용이 보이고, 받을 기기가 없어도 10분 동안 암호문으로 보관됩니다. 잠그지 않은 텍스트도 10분 동안 보관되지만 평문이라 그 범위의 누구나 볼 수 있습니다. 기기 이름표와 기기·브라우저 정보, 파일 크기와 보낸 시간은 잠기지 않습니다.

비밀번호를 잊어버리면 어떻게 하나요?

되찾을 방법이 없습니다. 비밀번호를 서버에 보관하지 않기 때문입니다. 보낸 기기에 원본이 있으면 새 비밀번호로 다시 보내면 됩니다.

QR 코드는 안전한가요?

QR과 그 주소에는 그 파일 하나의 열쇠가 들어 있어서, 가진 사람은 누구나 비밀번호 없이 받을 수 있습니다. 받을 사람에게만 보여 주고 단체방에 올리지 마세요. 열쇠는 주소의 # 뒤에 있어 서버 요청에는 실리지 않고, 파일이 삭제되거나 하루가 지나면 열리지 않습니다.

잠긴 파일은 얼마나 보관되나요?

일반 파일과 같습니다. 모든 기기가 페이지를 나가면 곧 삭제되고, 접속 중이어도 최대 약 1일이 지나면 정리됩니다. 받는 쪽은 미루지 말고 바로 풀어서 저장하세요.
