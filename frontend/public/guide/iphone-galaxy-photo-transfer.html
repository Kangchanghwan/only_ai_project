아이폰과 갤럭시끼리 사진·동영상 주고받기

아이폰으로 찍은 사진을 친구 갤럭시로 보내려면 보통 카톡을 씁니다. 그런데 메신저는 사진과 동영상을 압축해서 화질이 떨어지고, 긴 동영상은 용량 제한에 걸립니다. 에어드롭은 아이폰끼리만, 퀵쉐어는 안드로이드 쪽 기능이라 서로 다른 폰 사이에서는 막힙니다.

두 폰이 같은 와이파이에 있다면 브라우저로 해결됩니다. 양쪽에서 사이트를 열면 자동으로 연결되고, 고른 사진과 동영상이 원본 그대로 상대 폰에 나타납니다. 앱 설치도 가입도 없습니다.

보내는 방법

  1. 아이폰과 갤럭시를 같은 와이파이(같은 공유기)에 연결합니다. 집, 카페, 학교 와이파이 모두 됩니다.
  2. 아이폰은 사파리, 갤럭시는 삼성 인터넷이나 크롬에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크에 있는 기기는 같은 네트워크 탭에 자동으로 묶입니다. 가입, 로그인, 코드 입력이 없습니다.
  3. 보내는 폰에서 파일 업로드 카드를 누르고 사진이나 동영상을 고릅니다. 여러 장을 한 번에 골라도 되고, 진행률이 표시됩니다.
  4. 받는 폰 화면에 항목이 나타나면 다운로드 버튼으로 저장합니다. 갤럭시는 내 파일의 다운로드 폴더에 들어가고 갤러리에서도 보입니다. 아이폰은 파일 앱의 다운로드 폴더에 들어가며, 사진은 항목을 열어 길게 누른 뒤 이미지 저장을 고르면 사진 앱에 들어갑니다.

알아두면 좋은 것

  • 아이폰 사진이 HEIC 형식이라 받는 쪽에서 열리지 않으면, 아이폰 설정의 카메라에서 포맷을 높은 호환성으로 바꿔 두면 이후 사진은 JPEG로 저장됩니다. 전송 자체는 형식과 상관없이 그대로 됩니다.
  • 동영상처럼 큰 파일을 올리는 동안에는 보내는 폰 화면이 꺼지지 않게 두세요. 100MB가 넘는 파일은 끊겨도 같은 파일을 다시 고르면 이어서 올라갑니다.
  • 학교·카페처럼 여러 사람이 같은 와이파이를 쓰는 곳에서는 같은 네트워크 탭의 항목이 다른 사람에게도 보일 수 있습니다. 받은 뒤 바로 삭제하세요.
  • 두 폰이 다른 네트워크에 있다면 전체 공유 탭을 쓸 수 있지만, 이 탭의 항목은 서비스를 열어 둔 모든 사람에게 보입니다. 개인 사진은 같은 네트워크에서만 주고받으세요.

자주 묻는 질문

아이폰과 갤럭시 사이에는 에어드롭이나 퀵쉐어가 안 되나요?

에어드롭은 애플 기기끼리, 퀵쉐어는 주로 안드로이드와 윈도우 기기끼리 쓰는 기능이라 아이폰과 갤럭시 사이에서는 바로 되지 않는 경우가 많습니다. 브라우저는 두 폰 모두에 있으니 기종과 상관없이 같은 방법으로 주고받을 수 있습니다.

카톡으로 보낼 때처럼 화질이 떨어지나요?

아닙니다. 원본 파일을 그대로 전달하고 자동으로 압축하지 않습니다. 한 파일에 5GB까지 보낼 수 있어 긴 동영상도 됩니다.

앱을 설치하거나 가입해야 하나요?

필요 없습니다. 두 폰의 기본 브라우저만 있으면 되고, 계정이나 결제 기능이 없습니다.

보낸 사진은 서버에 계속 남나요?

모든 기기가 페이지를 닫으면 잠시 후 삭제되고, 접속 중이어도 최대 1일 안에 자동으로 정리됩니다. 받을 사진은 바로 저장해 두세요.
