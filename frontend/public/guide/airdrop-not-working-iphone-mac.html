에어드롭 안 될 때, 아이폰 사진·파일 맥으로 옮기기

아이폰에서 찍은 사진을 맥북으로 보내려고 에어드롭을 눌렀는데 맥이 목록에 안 뜨거나, 대기 중에서 멈춰 버릴 때가 있습니다. 블루투스를 껐다 켜고, 수신 설정을 바꾸고, 재부팅까지 하다 보면 사진 몇 장 옮기는 데 10분이 지나갑니다.

먼저 아래의 기본 확인을 해 보고, 그래도 안 되면 브라우저로 옮기면 됩니다. 아이폰과 맥이 같은 와이파이에 있으면 양쪽에서 사이트를 여는 것만으로 연결되고, 설치할 앱도 로그인할 계정도 없습니다.

옮기는 방법

  1. 에어드롭 기본 확인. 아이폰과 맥 모두 와이파이와 블루투스가 켜져 있는지, 아이폰의 개인용 핫스팟이 꺼져 있는지 확인합니다. 받는 쪽 에어드롭 수신이 연락처만으로 되어 있으면 연락처에 없는 기기는 목록에 나타나지 않으니 모든 사람(10분)으로 바꿔 보세요.
  2. 같은 와이파이에서 사이트 열기. 그래도 안 되면 아이폰과 맥을 같은 와이파이에 연결하고, 양쪽 브라우저(사파리, 크롬)에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크에 있는 기기는 같은 네트워크 탭에 자동으로 묶입니다. 입력할 코드도, 로그인도 없습니다.
  3. 아이폰에서 올리기. 아이폰 사파리에서 파일 업로드 카드를 누르고 사진 보관함 또는 파일 앱에서 고릅니다. 사진·동영상 여러 개를 한 번에 골라도 되고, 한 파일은 5GB까지 올라갑니다.
  4. 맥에서 저장. 맥 화면에 파일이 어느 기기에서 왔는지와 함께 바로 나타납니다. 다운로드 버튼으로 저장하세요. 파일은 최대 1일 안에 자동 정리되니 바로 받아 두는 것이 좋습니다.
  5. 반대 방향. 맥에서 아이폰으로 보낼 때는 파일을 페이지 위로 끌어다 놓거나 Cmd+V로 붙여넣으면 아이폰 화면에 나타납니다.

이럴 때 쓰기 좋습니다

  • 에어드롭 목록에 맥이 계속 안 나타날 때
  • 회사 맥이라 에어드롭 수신이 꺼져 있거나 바꿀 수 없을 때
  • 아이폰 사진을 맥과 윈도우 PC에 동시에 받아야 할 때
  • 아이클라우드 저장 공간이 가득 차서 사진 동기화가 멈췄을 때

알아두면 좋은 것

  • 여러 장을 보낼 때는 사진 보관함에서 한 번에 고르면 됩니다. 폴더째 보내려면 파일 앱에서 압축한 뒤 한 파일로 올리세요.
  • 방금 복사한 텍스트나 스크린샷은 붙여넣기 카드를 탭해 바로 올릴 수 있습니다.
  • 전체 공유 탭은 서비스를 열어 둔 모든 사람에게 보이므로 개인 사진에는 쓰지 말고, 같은 네트워크 탭에서 주고받으세요.

자주 묻는 질문

에어드롭과 무엇이 다른가요?

에어드롭은 근처 애플 기기끼리 인터넷 없이 주고받는 기능이라 아이폰·맥 조합에서는 잘 될 때 가장 빠릅니다. 이 방법은 파일이 서버를 한 번 거쳐 전달되므로 인터넷 연결이 필요하지만, 블루투스 검색이나 수신 설정에 영향을 받지 않고 윈도우·안드로이드 기기와도 똑같이 됩니다.

아이클라우드나 애플 계정이 필요한가요?

필요 없습니다. 브라우저만 있으면 되고 어떤 계정으로도 로그인하지 않습니다. 아이클라우드 저장 공간이 가득 차 있어도 상관없습니다.

동영상 화질이 떨어지지 않나요?

메신저처럼 자동으로 압축하지 않고 원본 파일을 그대로 전달합니다. 긴 동영상은 용량이 커서 업로드에 시간이 걸리지만, 100MB가 넘는 파일은 조각으로 나눠 올리므로 중간에 끊겨도 같은 파일을 다시 고르면 이어서 올라갑니다.

회사나 학교에서는 왜 상대 기기가 안 보이나요?

회사·학교는 유선망과 와이파이가 서로 다른 인터넷 출구를 쓰는 경우가 있어서 같은 네트워크 탭에 상대 기기가 보이지 않을 수 있습니다. 그럴 땐 두 기기를 같은 와이파이에 연결해 보세요.
