휴대폰 인증번호, PC로 바로 복사하기

PC에서 로그인이나 결제를 하다 보면 인증번호가 폰으로 옵니다. 6자리를 눈으로 보고 치다가 한 자리를 틀리거나, 3분 제한이 지나 다시 받는 일이 반복됩니다. 여섯 자리 숫자 하나 옮기려고 카톡 PC 버전을 켜는 것도 번거롭습니다.

폰과 PC가 같은 와이파이에 있다면, 폰에서 인증번호를 복사하고 한 번 탭하면 PC 화면에 바로 나타납니다. 항목을 누르면 클립보드에 들어가니 입력칸에 Ctrl+V만 하면 됩니다.

옮기는 방법

  1. 폰과 PC를 같은 와이파이에 연결합니다. 유선으로 연결된 PC라도 같은 공유기에 물려 있으면 됩니다.
  2. 양쪽 기기의 브라우저에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크에 있는 기기는 같은 네트워크 탭에 자동으로 함께 묶입니다. 입력할 코드도, 눌러야 할 초대 버튼도 없습니다. 인증번호를 자주 옮긴다면 폰 홈 화면에 추가해 두면 더 빠릅니다.
  3. 문자 앱에서 인증번호를 길게 눌러 복사합니다. 아이폰은 문자 위의 숫자를 길게 눌러 복사, 갤럭시는 메시지를 길게 눌러 텍스트 복사를 고르면 됩니다.
  4. Clipboard Share 페이지에서 붙여넣기 카드를 한 번 탭하고 클립보드 접근을 허용합니다. 복사한 텍스트가 바로 공유됩니다.
  5. PC 화면에 인증번호가 나타납니다. 항목을 클릭하면 클립보드에 복사되니, 인증번호 입력칸에 Ctrl+V로 붙여넣으세요.

알아두면 좋은 것

  • 갤럭시와 윈도우 조합이라면 윈도우의 휴대폰과 연결 앱으로 문자를 PC에서 바로 볼 수도 있습니다. 다만 처음 연결에 마이크로소프트 계정과 설정이 필요하고, 회사 PC에서는 설치가 막혀 있는 경우가 많습니다.
  • 아이폰과 맥 조합은 연속성 기능으로 클립보드가 공유되지만, 아이폰과 윈도우 또는 갤럭시와 맥 조합에는 그런 기능이 없습니다. 이 방법은 조합에 상관없이 브라우저만 있으면 됩니다.
  • 인증번호는 짧은 시간 뒤 만료되므로, 사이트를 미리 열어 둔 상태에서 문자를 받는 편이 좋습니다.
  • 두 기기가 다른 네트워크에 있다면 전체 공유 탭을 쓸 수 있지만, 이 탭의 항목은 서비스를 열어 둔 모든 사람에게 보입니다. 남에게 보이면 곤란한 파일은 같은 네트워크에서만 주고받으세요. 인증번호는 특히 같은 네트워크 탭에서만 다루세요.

자주 묻는 질문

인증번호가 서버에 남지 않나요?

모든 기기가 페이지를 닫으면 공유한 내용은 곧 삭제됩니다. 인증번호는 어차피 몇 분 뒤 만료되므로, 사용 후 탭을 닫으면 됩니다.

문자 앱이 자동으로 연동되나요?

아닙니다. 폰의 문자를 자동으로 읽어가지 않고, 복사한 뒤 붙여넣기 카드를 눌렀을 때만 공유됩니다. 권한도 그때 한 번만 묻습니다.
