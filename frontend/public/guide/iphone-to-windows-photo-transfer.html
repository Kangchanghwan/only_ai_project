아이폰 사진, 윈도우 PC로 케이블 없이 옮기기

아이폰에서 찍은 사진을 윈도우 PC로 옮기려면 보통 케이블을 꽂고 아이튠즈를 열거나, 메신저의 나에게 보내기로 한 장씩 넘기게 됩니다. 케이블은 늘 안 보이는 곳에 있고, 메신저를 거치면 사진이 눌려서 도착합니다.

두 기기를 같은 와이파이에 두고 브라우저만 열면 그 과정이 통째로 사라집니다. 아이폰에서 올린 사진이 몇 초 뒤 PC 화면에 나타나고, 설치할 앱도 만들 계정도 없습니다.

옮기는 방법

  1. 아이폰과 윈도우 PC를 같은 와이파이에 연결합니다.
  2. 양쪽 기기의 브라우저에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크에 있는 기기는 같은 네트워크 탭에 자동으로 함께 묶입니다. 입력할 코드도, 눌러야 할 초대 버튼도 없습니다.
  3. 사진 여러 장을 보낼 때는 화면의 파일 업로드 카드를 눌러 사진 앱에서 고르면 됩니다. 한 번에 여러 장을 선택해도 됩니다.
  4. 이미 복사해 둔 사진이나 스크린샷이라면 더 빠릅니다. 폰에서는 화면의 '붙여넣기' 카드를 한 번 탭하고 클립보드 접근을 허용하면 복사해 둔 텍스트나 이미지가 바로 공유됩니다. PC에서는 페이지 어디서나 Ctrl+V / Cmd+V를 누르면 됩니다.
  5. PC 화면에 사진이 바로 올라옵니다. 항목을 눌러 클립보드로 복사하거나, 다운로드 버튼으로 저장하세요.
  6. 반대 방향도 같습니다. PC에서 사진을 페이지 위로 끌어다 놓으면 아이폰 화면에 나타납니다.

알아두면 좋은 것

  • 두 기기가 다른 네트워크에 있다면 전체 공유 탭을 쓸 수 있지만, 이 탭의 항목은 서비스를 열어 둔 모든 사람에게 보입니다. 가족사진이나 신분증처럼 남에게 보이면 곤란한 파일은 같은 네트워크에서만 주고받으세요.
  • 모든 기기가 페이지를 닫으면 올려 둔 파일과 텍스트는 곧 삭제됩니다. 받을 파일은 미루지 말고 바로 저장하는 편이 좋습니다.
  • 아이폰 사파리에서 공유 버튼을 눌러 홈 화면에 추가해 두면 앱처럼 열리고, 사진 앱의 공유 시트에서 곧바로 보낼 수 있습니다. 브라우저를 먼저 열 필요가 없어집니다.
  • 업로드 카드에 표시된 최대 용량보다 큰 동영상은 나눠서 보내거나 압축해 주세요.

자주 묻는 질문

아이튠즈나 아이클라우드 계정이 필요한가요?

필요 없습니다. 브라우저만 있으면 되고, 애플 계정이나 마이크로소프트 계정으로 로그인하지 않습니다. 윈도우 PC에 아무것도 설치하지 않아도 됩니다.

사진 화질이 떨어지지 않나요?

메신저처럼 사진을 자동으로 압축하지 않고 파일을 그대로 전달합니다. HEIC 사진을 윈도우에서 열기 어렵다면, 아이폰 설정의 카메라에서 형식을 호환성 우선으로 바꾸거나 사진을 내보낼 때 JPEG를 선택하세요.
