PC방·공용 PC에서 로그인 없이 파일 주고받기

PC방이나 회사 공용 PC에서 사진 한 장, 문서 하나를 꺼내려고 메신저나 메일에 로그인하는 일이 많습니다. 로그아웃을 깜빡하면 대화 내용과 받은 편지함이 남의 자리에 그대로 남습니다.

잠깐 파일 하나 옮기자고 계정을 맡길 이유는 없습니다. 브라우저 탭 하나만 열면 폰과 공용 PC 사이에서 파일이 오가고, 자리에서 일어나면 흔적도 함께 사라집니다.

옮기는 방법

  1. 폰을 그 자리의 와이파이에 연결합니다. PC와 같은 네트워크에 있어야 서로를 찾습니다.
  2. 폰과 PC의 브라우저에서 https://www.clipboardapp.org/ 를 엽니다. 같은 네트워크의 기기는 같은 네트워크 탭에 자동으로 모입니다. 가입도, 입력할 코드도 없습니다.
  3. 폰에서 보낼 파일은 화면의 파일 업로드 카드를 눌러 고르고, PC에서는 파일을 페이지 위로 끌어다 놓습니다.
  4. 캡처나 복사로 끝나는 내용이라면 파일로 저장할 필요도 없습니다. 폰에서는 화면의 '붙여넣기' 카드를 한 번 탭하고 클립보드 접근을 허용하면 복사해 둔 텍스트나 이미지가 바로 공유됩니다. PC에서는 페이지 어디서나 Ctrl+V / Cmd+V를 누르면 됩니다.
  5. 반대편 기기에 항목이 바로 나타납니다. 눌러서 복사하거나 다운로드하세요.
  6. 다 옮겼으면 탭을 닫습니다. 모든 기기가 나가면 올려 둔 파일은 잠시 뒤 삭제됩니다.

공용 PC에서 특히 신경 쓸 것

  • PC방이나 카페처럼 여러 사람이 같은 와이파이를 쓰는 곳에서는, 같은 네트워크 탭에 올린 항목이 옆자리에서도 보일 수 있습니다. 민감한 파일은 이런 자리에서 아예 올리지 않는 편이 안전합니다.
  • 전체 공유 탭은 네트워크와 관계없이 서비스를 열어 둔 모든 사람에게 보입니다. 기본값이 아니고 직접 눌러야 켜지니, 공용 PC에서는 특히 잘못 눌리지 않았는지 확인하세요.
  • PC에 받은 파일은 다운로드 폴더에 남습니다. 자리를 뜨기 전에 직접 지우고, 브라우저 탭도 닫아 주세요.
  • 파일을 다른 사람 폰에 건네야 한다면 QR 코드를 띄워 카메라로 찍게 하면 됩니다. 상대가 주소를 입력할 필요가 없습니다.

자주 묻는 질문

공용 PC에 로그인 기록이 남나요?

로그인 자체가 없습니다. 아이디도 비밀번호도 입력하지 않으니 저장될 계정 정보가 없고, 브라우저에 남는 것은 방문 기록 정도입니다. 받은 파일만 지우고 탭을 닫으면 됩니다.

폰이 데이터(LTE)로 연결돼 있어도 되나요?

그러면 PC와 다른 네트워크로 잡혀 같은 네트워크 탭에서 서로 보이지 않습니다. 폰을 그 자리의 와이파이에 연결하는 것이 가장 확실하고, 여의치 않으면 전체 공유 탭을 쓰되 남에게 보여도 괜찮은 파일만 올리세요.
